# @parlor/shell-desktop

The desktop shell: runs and builds the app as a Tauri window on macOS, Windows and Linux. Installed by `@parlor/cli`; you do not depend on it directly.

```ts
import { TAURI_CONDITION } from "@parlor/shell-desktop";

console.log(TAURI_CONDITION);
```

Docs: https://cychien.github.io/parlor/guides/targets/
