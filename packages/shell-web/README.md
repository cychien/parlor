# @parlor/shell-web

The web shell: the Vite config every target builds from, file routes, the PWA and the content security policy. Installed by `@parlor/cli`; you do not depend on it directly.

```ts
import { FRAMEWORK_VITE_KEYS } from "@parlor/shell-web";

console.log(FRAMEWORK_VITE_KEYS);
```

Docs: https://cychien.github.io/parlor/guides/styling/
