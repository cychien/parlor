# @parlor/agent-ui

The agent's view of the app: route descriptions, views and the UI manifest an agent reads to know where the user is. Installed by `@parlor/client` and `@parlor/server`; you do not depend on it directly.

```ts
import { UI_MANIFEST_FILE } from "@parlor/agent-ui";

console.log(UI_MANIFEST_FILE);
```

Docs: https://cychien.github.io/parlor/guides/agent-sidebar/
