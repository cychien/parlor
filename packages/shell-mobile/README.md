# @parlor/shell-mobile

The mobile shell: runs and builds the app with Capacitor on iOS and Android. Installed by `@parlor/cli`; you do not depend on it directly.

```ts
import { CAPACITOR_CONDITION } from "@parlor/shell-mobile";

console.log(CAPACITOR_CONDITION);
```

Docs: https://cychien.github.io/parlor/guides/targets/
