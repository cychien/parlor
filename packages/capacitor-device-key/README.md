# @parlor/capacitor-device-key

The native half of the device-key and session-store capabilities on iOS and Android. Installed by `@parlor/capabilities` in Capacitor builds; you do not depend on it directly.

```ts
import { ParlorSessionStore } from "@parlor/capacitor-device-key";

console.log(typeof ParlorSessionStore);
```

Docs: https://parlor.dev/reference/capabilities/
